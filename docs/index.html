政策聚焦
教育部发布《义务教育阶段科学教育“做中学”领航行动指南》
教育部于2026年8月4日正式印发《义务教育阶段科学教育“做中学”领航行动指南》，旨在强化科学教育的实践性与探究性，推动教学方式变革。该指南强调通过动手实验和项目式学习，培养学生的科学素养与创新能力，对义务教育阶段的科学课程设置、教学评价及师资建设提出了系统性要求。

AI战略
教育部正式印发《中小学人工智能通识教育指南》，覆盖全学段
2026年，教育部正式印发《中小学人工智能通识教育指南》，明确要求人工智能通识教育覆盖全学段。该指南标志着AI教育从试点走向规模化普及，要求学校将AI素养纳入课程体系，推动人工智能与基础教育的深度融合，旨在培养适应智能时代的创新型人才。

民办监管
北京发布民办高校年度检查新规，强化资产与财务监管
北京市教委发布2026年1号文件，针对民办高等学校及非学历高等教育机构，重点强化对举办者抽逃资金、挪用办学经费等行为的审查。新规要求非营利性民办学校收费及活动资金必须使用备案账户，并依据教育部《民办高等学校年度检查指标体系》对资产与财务管理进行严格审计。
来源：北京市教委2026-02-05阅读原文 →

行业趋势与市场
行业整合
教育行业资本运作活跃：传智教育双线并购，Coursera与Udemy合并
2026年教育行业整合加速。传智教育以1.06亿元收购优优汇联51%股权切入跨境电商培训，并以8200万元收购新加坡辅仁控股51%股权开拓国际教育版图。同时，全球在线教育巨头Coursera与Udemy以约25亿美元估值完成合并，打通“学历+技能”双通道，标志着行业从分散竞争走向巨头整合。

课程选择
IB、A-Level、AP、DSE四大国际课程体系全面对比解析
2026年初，针对国际课程选择的家庭需求，业内发布四大主流课程体系（IB、A-Level、AP、DSE）的深度对比分析。报告从课程特点、适合学生类型、升学方向及难度等维度进行拆解，指出IB注重全人教育，A-Level适合英联邦方向，AP指向美加，DSE则面向香港升学，帮助家庭做出更科学的路径规划。

教育行业大洗牌：体育拔高与AI主导改写行业格局
2026年，教育行业经历深度洗牌。传统的“拼时间、堆刷题”模式被摒弃，体育教育和AI教育成为两大核心驱动力。AI教育兼顾升学竞争力与身心发展，以高效学习替代低效消耗，让孩子在守护身心健康、发展兴趣特长的同时掌握升学主动权。行业格局正从单一分数导向转向综合素质与科技赋能并重。
