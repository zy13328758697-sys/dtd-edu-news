政策聚焦
教育部启动“人工智能+”教育教学重大专项课题立项
教育部学校规划建设发展中心发布关于“人工智能+”教育教学（第一批）重大专项课题立项的通知，标志着国家层面正式将AI赋能教育从理念探讨推向实践研究阶段。该专项聚焦AI与教学场景的深度融合，旨在通过课题研究推动教育模式变革，为各级各类学校开展AI教育应用提供理论支撑与实践路径。

民办监管
北京发布民办高校年检新规，强化资产与财务监管
北京市教委发布京教民〔2026〕1号文件，针对民办高校及非学历高等教育机构提出更为严格的年度检查指标。新规重点聚焦举办者及关联单位是否存在抽逃资金、挪用办学经费等行为，强调学校收费须使用备案账户，支出须主要用于教育教学活动，旨在引导规范民办教育健康有序发展。
来源：jw.beijing.gov.cn阅读原文 →

心理健康
教育部出台十项措施，全面加强中小学生心理健康工作
在2026年全国教育工作会议上，教育部提出《进一步加强中小学生心理健康工作十条措施》，聚焦缓解学生考试开学焦虑、落实“体育每天2小时”、保障充足睡眠时间、培养健康用网习惯等关键领域。此举将心理健康教育提升至前所未有的高度，要求学校将相关工作融入日常教学与管理全过程。
来源：www.moe.gov.cn阅读原文 →

行业趋势与市场
课程选择
国际学校课程选择指南：IB、AP、A-Level三大体系差异深度解析
随着国际教育低龄化趋势明显，如何选择课程体系成为家长关注焦点。业内专家指出，IB强调全人教育与文理均衡，AP侧重学科深度与个性化发展，A-Level则偏向专业培养与单科深耕。专家建议，课程选择不应简单与留学目的地挂钩，而应基于学生的学术能力、兴趣特长及时间管理能力综合判断。

AI教育
AI教育机器人市场持续升温，硬件+内容成竞争核心
以亚博智能为代表的AI教育机器人制造商持续迭代产品，反映出教育硬件智能化趋势加速。当前市场已从单一硬件销售转向“硬件+课程+平台”的综合生态竞争，AI机器人正逐步成为K12阶段编程教育、STEAM教育的重要载体，推动教学模式向互动性、体验式方向变革。

IB、AP、A-Level怎么选？专家：适合的才是最好的
