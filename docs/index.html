政策聚焦
教育部发布《教育发展“十五五”规划》答记者问，明确未来五年教育发展基调
教育部负责人就《教育发展“十五五”规划》答记者问，为2026-2030年的教育发展定调。规划预计将聚焦教育强国建设、教育数字化转型、拔尖创新人才培养等核心议题。对于民办教育，规划或将进一步强调规范与高质量并重，引导民办学校走特色化、内涵式发展道路，这与德英乐等优质民办教育集团的长期发展方向高度契合。

AI+教育
教育部新闻发布会介绍《“人工智能+教育”行动计划》进展，推动教育模式变革
教育部在新闻发布会上介绍了《“人工智能+教育”行动计划》的相关情况，预示着AI技术将在教育教学全场景中加速落地。该行动计划将推动AI在个性化学习、智能评测、管理优化等方面的应用，并强调提升师生数字素养。对于K12学校而言，如何将AI工具与现有双语课程体系深度融合，将成为提升教学质量和效率的关键。

规范管理
北京市发布民办高校年度检查指标，强化非营利性民办学校财务监管
北京市教委发布文件，明确对民办高校的年度检查指标体系，重点审查举办者及关联单位是否存在抽逃资金、挪用办学经费等行为，并强调非营利性民办学校的资金往来须使用备案账户。此举虽针对高校，但释放出政府对民办教育财务规范管理持续收紧的信号，对K12民办学校具有重要的警示和参照意义。

行业趋势与市场
AI趋势
多鲸行研发布《2025 AI赋能教育行业发展趋势报告》，聚焦十大核心趋势
报告深度解析了AI赋能教育行业的政策、市场、技术与行业格局，提出十大核心趋势。报告指出，AI正从工具层面走向重塑教育模式，To G（教育信息化）、To B（教育企业）、To C（教育培训）的商业模式将发生深刻变革。个性化学习、自适应教学和智能评价体系将成为未来教育产品的标配，对传统教育机构提出转型要求。
来源：TopMarketing2026-06-01阅读原文 →

深度报道：国际学校“催生”史，资本与教育互搏二十年
界面新闻深度回顾了国际教育行业二十年发展历程，指出2014年政策紧缩后，国际教育开始从纯外籍人员子女学校下沉至K12阶段的民办学校。文章分析了资本在教育扩张中的作用与博弈，并指出随着留学普及和家长需求多元化，国际教育正进入品牌化、差异化竞争的新阶段，单纯依靠资本驱动难以为继。

K12教培政策持续收紧，行业合规成本与转型压力并存
