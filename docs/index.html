政策与监管动态
民办监管
北京发布民办高校年度检查新规，重点核查资金挪用与关联交易
北京市教委发布京教民„2026‟1号文件，针对民办高等学校及非学历高等教育机构启动年度检查。文件依据教育部《民办高等学校年度检查指标体系》，重点核查举办者及关联单位是否存在抽逃资金、挪用办学经费等行为，并强调非营利性民办学校费用及活动资金须使用备案账户。此举旨在引导规范民办高等教育健康有序发展。
来源：jw.beijing.gov.cn2026-02-05阅读原文 →
德英乐视角
北京年检新规对资金监管的强化预示着全国民办教育治理趋严。德英乐作为K-12集团，需持续确保财务合规，尤其在关联交易和账户管理上保持高度透明。
科学教育
教育部印发《义务教育阶段科学教育“做中学”领航行动指南》
教育部于2026年8月正式印发《义务教育阶段科学教育“做中学”领航行动指南》，旨在推动义务教育阶段科学教育的实践性变革。该指南强调通过动手实践和项目式学习培养学生的科学素养与创新能力，为学校开展科学课程提供了具体的行动框架和指导方向。
来源：www.moe.gov.cn2026-08-04阅读原文 →
德英乐视角
“做中学”指南与德英乐探究式教学理念高度契合。我们可借此契机，进一步强化STEAM课程体系中的实践环节，凸显双语科学教育的差异化优势。
教师减负
教育部详解教师减负新政，聚焦中小学教师非教育教学负担
教育部教师工作司负责人就《关于进一步减轻中小学教师非教育教学负担若干措施的通知》答记者问。新政旨在清理和规范影响中小学教师正常教育教学的各类督查、检查、评比、考核等事项，将时间还给教师，聚焦教学主业，提升教育质量。此举是对基层教师工作生态的重要干预。
来源：www.moe.gov.cn2025-11-10阅读原文 →
德英乐视角
教师减负政策有助于提升教师职业幸福感与教学专注度。德英乐应积极响应，优化内部管理流程，减少非教学事务干扰，保障师资队伍的稳定性与教学质量。
行业趋势与市场
AI元年
专家观点：2026年成为全球AI教育全面启动元年
中国成人教育协会专家岑建君撰文指出，2026年被确立为全国AI教育全面启动元年。中国、美国、韩国、芬兰等相继发布国家级AI教育战略，重点推进AI进课程、进教学、进评价。据统计，全球超70%的国家和地区已出台专项政策，将2026年视为AI教育从试点走向规模化的核心起点。
来源：www.caea.org.cn2026-03-10阅读原文 →
德英乐视角
全球AI教育元年的到来，要求德英乐必须加速AI与双语课程的深度融合，不仅作为工具，更要作为通识素养，培养未来人才的核心竞争力。

教育行业大洗牌：资本并购与AI主导格局初现
2026年教育行业呈现两大趋势：一是资本驱动的行业整合加速，如传智教育收购优优汇联及新加坡辅仁控股，Coursera与Udemy完成约25亿美元估值合并；二是AI教育成为主导力量，教育部正式印发《中小学人工智能通识教育指南》，要求AI通识教育覆盖全学段，彻底改写行业竞争格局。
来源：www.xhby.net2026-08-15阅读原文 →
德英乐视角
行业洗牌加剧，头部集团通过资本与AI构建护城河。德英乐需关注同业动态，坚持高质量办学，同时探索AI赋能下的管理效能提升与个性化学习路径。
人才需求
2026人才市场洞察：教育培训行业招聘需求稳中有升
据聚仕人才发布的《2026人才市场洞察与薪酬报告》显示，2026年第一季度我国教育培训行业招聘需求稳中有升，第二季度有36.2%的企业计划扩招，教育培训/科研行业展现出强烈的招聘扩张意愿。同时，行业呈现出与科技、技能培训双重融合的趋势。
来源：www.jushihr.com2026-07-15阅读原文 →
